# Metastasis Streamlit Assets

Ce dossier contient les captures d'ecran utilisees dans le README du sous-projet
Metastasis.

Captures attendues :

- `streamlit-home.png` : page d'accueil Streamlit avec checkpoint local charge.
- `prediction-non-metastatic.png` : prediction sur un patch `non_metastatic` du test set local.
- `prediction-metastatic.png` : prediction sur un patch `metastatic` du test set local.

Ces images sont destinees a rendre la demo portfolio lisible sur GitHub. Les donnees
sources, les sorties d'evaluation, les checkpoints et les tokens restent locaux et ne
sont pas versionnes.
