# Captures MultiCancer V1

Ce dossier contient les captures portfolio du hub Streamlit final.

| Fichier | Parcours documente |
| --- | --- |
| `multicancer-home.png` | Accueil, selection explicite et disclaimer global |
| `leukemia-prediction.png` | Prediction Leukemia, probabilites et Grad-CAM |
| `breast-prediction.png` | Prediction Breast reelle et contexte patient-aware |
| `metastasis-threshold-analysis.png` | Prediction Metastasis et exploration du seuil |
| `lung-colon-multiclass.png` | Mode LungColon cinq classes |
| `lung-colon-binary.png` | Mode LungColon `benign` / `malignant` |

Les captures proviennent de vraies sorties locales. Une prediction incorrecte peut etre
conservee lorsqu'elle illustre une limite utile ; elle n'est jamais modifiee pour rendre
le resultat plus favorable.

Les images source, datasets, outputs et checkpoints restent locaux et non versionnes.
Les captures ne doivent contenir ni information personnelle ni chemin utilisateur
sensible.
